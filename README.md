این افزونه به شما کمک میکنه تا صفحات چپ چین رو راست چین کنید!

طبق این آموزش، مرحله به مرحله پیش برید و افزونه رو به گوگل کروم اضافه کنید!

1. بالا روی Code کلیک کنید و پروژه رو دانلود کنید

2. روی DownloadZip کلیک کنید.

3. فایل دانلود شده رو کلیک راست کنید و از حالت زیپ خارج کنید

4. کروم رو باز کنید و وارد تنظیمات بشید. (بالا سمت راست، روی سه نقطه بزنید و Setting/تنظیمات رو انتخاب کنید)

5. به قسمت extensions/افزونه ها بروید.

6. بالا سمت راست Developer mode رو فعال کنید.

7. بالا سمت چپ Load Unpacked رو کلیک کنید.

8. در پنجره باز شده، به آدرسی برید که فایل Zip رو از حالت Zip خارج کردید و وارد اون پوشه بشید و Select Folder رو بزنید.
