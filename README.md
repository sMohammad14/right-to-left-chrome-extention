سلام!

این افزونه به شما کمک میکنه تا صفحات چپ چین رو راست چین کنید!

طبق این آموزش، مرحله به مرحله پیش برید و افزونه رو به گوگل کروم اضافه کنید!

1. بالا روی Code (سبز رنگ 🟢) کلیک کنید.

2. روی DownloadZip کلیک کنید.

3. فایل دانلود شده رو کلیک راست کنید و از حالت زیپ خارج کنید.

4. کروم رو باز کنید و وارد تنظیمات بشید. (بالا سمت راست، روی سه نقطه بزنید و Setting/تنظیمات رو انتخاب کنید)

5. به قسمت extensions/افزونه ها بروید.

6. بالا سمت راست Developer mode رو فعال کنید.

7. بالا سمت چپ Load Unpacked رو کلیک کنید.

8. در پنجره باز شده، به آدرسی برید که فایل Zip رو از حالت Zip خارج کردید و وارد اون پوشه بشید و Select Folder رو بزنید. (نام پوشه از زیپ خارج شده right-to-left-chrome-extention-main است. انقدر بابد داخل پوشه برید تا چیزی برای کلیک نباشه و سپس پایین سمت راست، Select Folder رو انتخاب کنید)

9. روی علامت پازل کنار سه نقطه ها (بالا راست) کلیک کنید و علامت سنجاق کنار Right to Left for Z-RKH رو انتخاب کنید.

10. یک دایره به نمایش داده میشود.

11. به Tab/صفحه ای که میخواهید راست چین شود مراجعه کنید. (اگر صفحه از قبل باز بوده لازم است Refresh کنید)

12. روی دایره کلیک کنید و افزونه را فعال کنید!

🌷 با هر بار فعال و غیر فعال کردن افزوه، فرازی از دعای جوشن کبیر با ترجه فارسی نشان داده خواهد شد!
